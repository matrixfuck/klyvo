# История версий

Формат — [SemVer](https://semver.org/lang/ru/): `major.minor.patch`.
Пока версия ниже 1.0.0, ломающие изменения возможны в любом `minor`.

## v0.7.0 — 2026-08-10

Дашборд переработан.

- Единый стиль с лендингом (тёмный интерлок, mono-заголовки, сигналы amber/red/mint).
- Вкладки: Перехваты · Правила · Активность. Поиск по каждой + фильтр по решению
  (deny/ask) для перехватов.
- Визуализация соотношения deny/ask, относительное время («5 мин назад»),
  панель правил с частотой срабатываний и уровнем.
- Авто-обновление (переключатель), пустые состояния, адаптив.
- API отдаёт список действующих правил с частотой (`collect()` → `rules`,
  `stats.rules_active`).

## v0.6.0 — 2026-08-10

Поддержка Codex, Kimi Code и opencode — всего 6 агентов.

- **Codex CLI** (`--tool codex`): отдельный адаптер `adapters/codex_guard.py`.
  Codex строго отвергает лишние поля и реагирует только на `deny`, поэтому ответ
  плоский (`{"permissionDecision":"deny",…}`), без hookSpecificOutput-обёртки;
  предупреждения пропускаются, но пишутся в журнал. Установщик кладёт `hooks.json`
  и включает `[features] codex_hooks = true` в `config.toml`.
- **Kimi Code CLI** (`--tool kimi`): формат хуков совпадает с Claude Code, поэтому
  используется тот же `guard.py`/`journal.py`. Установщик пишет `[[hooks]]` в
  `config.toml`.
- **opencode** (`--tool opencode`): плагин на JS (`tool.execute.before`), который
  зовёт ядро правил через новый CLI `klyvo_rules.py scan` (JSON-вывод) и блокирует
  критичное через `throw`.
- Хуки берут корень проекта из `cwd`, если `CLAUDE_PROJECT_DIR` не задан.
- Тесты `tests/test_agents.py` (Codex-адаптер, установщики Codex/Kimi/opencode,
  CLI scan). Все агенты по спеке — живьём пока не проверены.

## v0.5.0 — 2026-08-10

Лендинг klyvo.tech и удобный вход в дашборд.

- Лендинг (`site/index.html`) — self-contained, без внешних зависимостей и шрифтов:
  сигнатурный терминал показывает, как безопасная команда проходит, а `DROP TABLE`
  блокируется. Разделы: почему мало отката, что ловит, установка, приватность.
- Вход в дашборд: сессионная авторизация вместо HTTP basic-auth. Пароль хранится
  как scrypt-хэш, сессия — HMAC-подписанная кука (HttpOnly, Secure, SameSite).
  `python3 klyvo_web.py --set-password <user>`; включается через env
  `KLYVO_WEB_AUTH`/`KLYVO_WEB_BASE`. Без них — локальный режим без входа.
- Тесты `tests/test_web.py` расширены: пароль (верно/неверно), сессии (валидна/
  подделка/пустая/истёкшая), режим без входа.

## v0.4.0 — 2026-08-09

Локальный веб-дашборд (первая простая версия).

- `python3 klyvo_web.py` поднимает дашборд на `127.0.0.1:8765`: сводка
  (перехвачено, critical/warning, топ правил, действий агента), таблица
  перехваченных команд и активность сессии. Данные читаются из `.klyvo/`.
- Только локально, без сети и без внешних зависимостей (стандартная библиотека).
  Флаги `--project` и `--port`.
- Тесты `tests/test_web.py` (сбор данных, битые строки, порядок).

## v0.3.0 — 2026-08-09

Маскировка секретов в журнале.

- Перед записью текст команды прогоняется через `klyvo/redact.py`: пароли в
  строках подключения, `TOKEN`/`SECRET`/`API_KEY`-присваивания,
  `Authorization`-заголовки и ключи известных форматов (`sk-`, `ghp_`, AWS,
  Google) заменяются на `***`. Форма команды сохраняется, читаемость не страдает.
- Применяется в обоих журналах (`journal.jsonl` и `session_log.jsonl`).
- Тесты `tests/test_redact.py` (юнит + проверка, что секрет не попадает в журнал).

## v0.2.0 — 2026-08-09

Поддержка DeepSeek-Code и других форков Claude Code.

- Установщик: пресет `--tool deepseek-code` (пишет в `~/.deepseek-code/settings.json`)
  и универсальный `--tool claude-compatible --path <settings.json>` для любого
  форка с нестандартным путём конфига. Форки используют тот же контракт хуков,
  что и Claude Code, поэтому ставятся тем же `guard.py`/`journal.py`.
- Хуки `guard.py`/`journal.py` больше не зависят от `CLAUDE_PROJECT_DIR`
  (форки её не задают): корень проекта берётся из `cwd` payload'а, затем из
  текущей директории.
- Тесты установщика (`tests/test_install.py`): запись, идемпотентность,
  удаление, сохранность чужих ключей в конфиге.

## v0.1.0 — 2026-08-08

Первая публичная бета.

- Перехват разрушительных команд с базой данных до выполнения агентом.
  Критичное блокируется (работает даже в режиме автоодобрения), на
  предупреждения запрашивается подтверждение.
- Ядро правил `klyvo/rules.py`: 36 правил и 2 эвристики (SQL, CLI СУБД,
  миграции, облачные БД, NoSQL, инфраструктура с данными), уровни
  critical/warning, ловля обхода `WHERE`.
- Журнал перехваченных попыток в `.klyvo/journal.jsonl`.
- Сквозной журнал сессии: `journal.py` + `klyvo_journal.py`, сводка без нейросети.
- Настройка через `.klyvo/config.json`: `disabled_rules`, `allowlist`,
  `custom_rules`. CLI `klyvo_rules.py` (`list`, `test`).
- Адаптеры: Claude Code (`PreToolUse`/`PostToolUse`) и Cursor
  (`beforeShellExecution`). Установщик `tools/install_hooks.py`.
