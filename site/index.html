У Claude Code и Cursor есть свой откат правок. Но у него две дыры — и обе там, где живёт настоящий риск.

✕ Он не видит bash

Миграции, psql, CLI баз данных — почти всегда команды в терминале. Встроенный откат их не отслеживает.

✕ Он не трогает внешнее

Удалённую строку в проде, отправленный API-запрос, уже прошедший деплой откат файлов не вернёт. Klyvo срабатывает до выполнения.

Какие агенты защищены

Ядро детекции и журнал общие для всех — под каждый инструмент только тонкий адаптер под его формат хуков. Живая проверка блокировки подтверждена на Claude Code; у остальных адаптеры собраны по официальной спеке и покрыты юнит-тестами, живой тест на реальном агенте — впереди. Это бета: возможны баги, особенно на свежих адаптерах — нашли один, откройте issue на GitHub.

Поставить на Claude Code

Нужен только Python 3 и git. Для другого агента из списка выше добавь его имя параметром. Не хочешь запускать скрипт из интернета — ставится и вручную, тремя командами из INSTALL.md.

01 — ПОСТАВИТЬ

Одна команда

$ curl -fsSL \
  https://klyvo.tech/\
  install.sh | sh

Кладёт код в ~/klyvo и аккуратно дописывает хук, остальные настройки не трогает.

02 — ПЕРЕЗАПУСТИТЬ

Перезапустить агента

Хуки читаются при старте. Дальше guard работает молча и вмешивается только на опасном.

03 — ПРОВЕРИТЬ

Убедиться, что живой

Попроси агента выполнить безобидную команду с триггерным словом внутри — например echo с текстом про очистку таблицы. Она должна быть перехвачена.

приватность

Всё остаётся у тебя

  • Ни одного сетевого вызова — детекция локальная, без обращений к API.
  • Журнал пишется только на твой диск, в .klyvo/.
  • Пароли и токены в командах маскируются перед записью в лог.
