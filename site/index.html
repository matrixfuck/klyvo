Klyvo перехватывает разрушительные команды — DROP, TRUNCATE, DELETE без WHERE, сброс миграций — до того, как их выполнит Claude Code, Cursor или другой AI-агент. Работает даже в авто-режиме.

Почему одного отката мало

Откат кода не вернёт удалённые данные

У Claude Code и Cursor есть свой откат правок. Но у него две дыры, и обе — там, где живёт настоящий риск.

Он не видит bash

Миграции, psql, CLI баз данных — это почти всегда команды в терминале. Встроенный откат их не отслеживает.

Он не трогает внешнее

Удалённую строку в проде, отправленный API-запрос, уже прошедший деплой откат файлов не вернёт. Klyvo срабатывает до выполнения.

Что Klyvo ловит

Смотрит текст команды до запуска. Критичное блокирует жёстко, спорное выносит на подтверждение.

Чистый SQL
DROP · TRUNCATE · ALTER … DROP COLUMN
DELETE / UPDATE без WHERE
включая обманки WHERE 1=1
Сброс миграций
Prisma, Rails, Django, Alembic, Knex…
Облачные БД
supabase db reset, D1, Turso
NoSQL
dropDatabase(), deleteMany({}), FLUSHALL
Инфраструктура
docker volume rm, terraform destroy
Три шага

Поставить на Claude Code

Работает на macOS и Linux, нужен только Python 3. Форки Claude Code (DeepSeek-Code и др.) — тем же способом.

01

Скачать

git clone \
 https://github.com/matrixfuck/klyvo.git \
 ~/klyvo
02

Поставить хук

python3 \
 ~/klyvo/tools/install_hooks.py

Аккуратно дописывает хук, остальные настройки не трогает.

03

Перезапустить агента

Хуки читаются при старте. Готово — guard активен.

Приватность

Всё остаётся у тебя

  • Ни одного сетевого вызова — детекция локальная, без обращений к API.
  • Журнал пишется только на твой диск, в .klyvo/.
  • Пароли и токены в командах маскируются перед записью в лог.
